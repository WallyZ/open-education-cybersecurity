# Cybersecurity Foundations Starter Study Plan

## Goal

Build practical, ethical understanding of core cybersecurity foundations: networking, identity, system hardening, threat modeling, and incident response.

## Objectives

- Explain common network components and packet flow.
- Identify basic authentication and authorization risks.
- Build a simple threat model for a small application.
- Practice safe incident triage from logs and symptoms.

## Milestones

1. Networking baseline and terminology.
2. Identity and access control fundamentals.
3. Threat modeling a small service.
4. Incident response tabletop exercise.

## Evidence

- Short-answer checks.
- Scenario walkthroughs.
- Lab notes with source attribution.
